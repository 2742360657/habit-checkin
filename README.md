# 打卡喵

基于 Expo + React Native + TypeScript 的本地待办与习惯 App。数据保存在设备本地，可导出 JSON 备份并覆盖恢复。

## 当前页面

- 今天：按紧急程度展示逾期/今日待办，并汇总习惯进度和少量无日期待办。
- 待办：支持无日期或带截止日期/时间的任务、重要标记、完成撤销、智能排序和自定义拖动排序。
- 习惯：支持每日、每周、每月目标，分组、打卡、历史、归档和手动排序。
- 设置：主题、分组管理、归档习惯、数据备份与恢复。

## 主要交互

- 待办有截止时间时，智能视图按“逾期、今天、明天、未来 7 天、稍后、无日期”排列。
- 切换到待办“自定义”视图后，可以进入拖动排序；智能视图不会因拖动暗中改变日期。
- 习惯分组和组内习惯都可以进入明确的拖动排序页。
- 习惯卡片右侧 `+1` 立即记录，底部提示支持撤销；标题进入历史，`•••` 打开编辑与归档菜单。
- 历史默认打开月视图并记住最近使用的月/年模式；年视图使用月份摘要，不再堆叠十二个完整小日历。

## 数据版本

当前 `AppData.version` 为 `5`。旧版 `version: 1` 至 `version: 4` 会在读取时自动迁移：

- 现有习惯、分组、归档状态、主题和打卡记录保持不变。
- 旧习惯默认迁移为“每天 1 次”。
- 分组和习惯按旧数组顺序生成可持久化的 `order`。
- 新增空的待办列表，不影响原有数据。

备份文件包含待办、习惯、顺序、周期设置、打卡记录和主题。

## 运行

```bash
npm install
npm run android
```

Web 调试：

```bash
npm run web
```

## 校验

```bash
npx tsc --noEmit
npx expo export --platform android --output-dir dist
npm run test:smoke-web
```

`test:smoke-web` 会复用 Windows 已安装的 Microsoft Edge，覆盖今天页、待办新增/完成/撤销、习惯周期、自定义视图和拖动排序。
